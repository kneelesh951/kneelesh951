## About Me

I build at the intersection of **agentic AI**, **cloud infrastructure**, and **full-stack engineering**. My work spans designing autonomous multi-agent systems powered by LLMs, architecting production-grade cloud environments on AWS and Azure, and shipping complete products from infrastructure to UI.

- 🤖 Building **DIA** — a voice-first, multi-agent AI operating layer for macOS powered by Claude
- ☁️ Designing and automating cloud infrastructure on **AWS** and **Azure** with Terraform & IaC
- 🔐 Embedding security into every layer of the delivery pipeline with **DevSecOps** practices
- 🏗️ Shipping full-stack products with **Next.js, TypeScript, Node.js, and PostgreSQL**
- 📫 **kneelesh951@gmail.com**
