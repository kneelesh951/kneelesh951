## About Me

I design and ship full-stack products end-to-end — from cloud infrastructure to production-ready UI. My work spans provisioning and automating AWS environments with **Terraform**, and building complete SaaS platforms with **Next.js, TypeScript, and PostgreSQL**. I care about clean architecture, zero-downtime deployments, and systems that are as maintainable as they are functional.

- 🏗️ Currently building **Offmap** — a peer-to-peer local-experience platform (Next.js, Supabase, Stripe)
- ☁️ Automating cloud infrastructure provisioning on **AWS** using **Terraform** and CI/CD workflows
- 🌱 Focused on production-grade patterns: mock/prod parity, zero-downtime migrations, layered architecture
- 📫 Reach me at **kneelesh951@gmail.com**
