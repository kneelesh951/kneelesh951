## About Me

I build at the intersection of **agentic AI**, **cloud infrastructure**, and **full-stack engineering**. My work spans designing autonomous multi-agent systems powered by LLMs, architecting production-grade cloud environments on AWS and Azure, and shipping complete products from infrastructure to UI — with security embedded at every layer.

- 🤖 **DIA** — voice-first agentic AI operating layer for macOS, built on Claude with 8 specialist autonomous agents
- 🗺️ **Offmap** — peer-to-peer local-experience SaaS platform (Next.js, Supabase, Stripe)
- ☁️ Designing and automating cloud infrastructure on **AWS** and **Azure** with Terraform & IaC
- 🔐 Embedding security into CI/CD pipelines with **DevSecOps** — SAST, secrets management, least-privilege IAM
- 📫 **kneelesh951@gmail.com**
